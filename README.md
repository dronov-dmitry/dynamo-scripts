# ScriptStore — Магазин скриптов для Revit/Dynamo

🔗 **Сайт приложения**: [https://dronov-dmitry.github.io/dynamo-scripts/](https://dronov-dmitry.github.io/dynamo-scripts/)

## Что это

Платформа для покупки и скачивания скриптов Dynamo — инструментов автоматизации для Autodesk Revit. Архитекторы и BIM-инженеры покупают готовые скрипты и используют их в своей работе.

## Что можно делать

- **Покупать скрипты** — каталог готовых скриптов для автоматизации задач в Revit
- **Скачивать купленные скрипты** — один клик в личном кабинете, скрипт загружается в Dynamo
- **Управлять лицензиями** — видеть свои покупки, проверять статус доступа
- **Пополнять баланс** — через криптовалюту (Bitcoin, USDT и другие)
- **Авторизоваться через Яндекс или Google** — быстро войти без запоминания пароля

## Какие выгоды

- **Экономия времени** — не нужно писать скрипты самому, берёшь готовый и работаешь
- **Безопасно** — каждый скрипт проверен, имеет контрольную сумму, ты точно знаешь что скачиваешь
- **Удобно** — всё в одном месте: каталог, покупки, скачивания
- **Доступно из любой страны** — зеркала работают в разных регионах, авторизация через Яндекс всегда доступна

## Для кого

Для архитекторов, BIM-инженеров и всех, кто работает с Autodesk Revit и хочет автоматизировать рутинные задачи с помощью готовых скриптов Dynamo.
